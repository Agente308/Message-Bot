# Message-Bot
Aplicación desarrollada en Python + Discord.py + PySide6 que permite crear y enviar embeds totalmente personalizados a un canal de Discord, con vista previa en tiempo real y selector de emojis del servidor.

Para usarlo primero que necesitas es crear un bot en el portal oficial de Discord. Entra a la página https://discord.com/developers/applications

e inicia sesión con tu cuenta. Una vez dentro, verás tu panel de aplicaciones. En la parte superior derecha aparecerá el botón “New Application”. Haz clic ahí, elige un nombre para tu aplicación y créala. Cuando la aplicación esté lista, observa el menú del lado izquierdo y entra a la sección llamada “Bot”. Dentro verás un botón que dice “Add Bot”. Confírmalo y con eso tu aplicación ya tendrá un bot real asociado.

Ahora debes obtener el token de tu bot. Sigue dentro de la sección “Bot”, baja un poco y encontrarás el apartado de “Token”. Presiona el botón “View Token” o “Reset Token”. Discord te pedirá verificar tu cuenta y después te mostrará el token. Ese token es lo que debes colocar dentro de tu archivo MessageBot.py exactamente en la línea donde aparece la variable llamada TOKEN. Dentro del código hay una línea que dice TOKEN = "tu_token_aqui"; reemplaza todo lo que hay entre comillas y pon tu token real ahí. No pongas espacios y no quites las comillas.

Después debes invitar el bot a tu servidor. Para hacerlo, vuelve al menú izquierdo y abre la sección “OAuth2”, luego entra a “URL Generator”. En el apartado de “Scopes” selecciona la opción “bot”. Baja un poco hasta llegar a la sección de permisos y habilita como mínimo “Send Messages” y “Embed Links”, aunque puedes activar otros si quieres funciones extras. Cuando termines, en la parte inferior te aparecerá un enlace generado automáticamente. Cópialo, pégalo en tu navegador y Discord te pedirá seleccionar el servidor donde quieres añadir el bot. Autoriza la invitación. Una vez hecho eso, verás el bot dentro de tu servidor, aunque aparecerá offline porque todavía no has ejecutado tu programa.

Antes de ejecutar MessageBot.py debes obtener el ID del canal donde quieres enviar los embeds. Para eso necesitas activar el modo desarrollador de Discord. Abre Discord, ve a Configuración de usuario en la parte inferior izquierda, entra a la categoría “Avanzado” y habilita la opción “Modo Desarrollador”. Cuando esté encendido, vuelve al servidor, haz clic derecho sobre el canal donde quieras que tu bot mande mensajes y selecciona la opción “Copiar ID”. Ese número es el ID del canal. Tu programa lo pedirá cuando arranque.

Ya con token y canal listos, abre MessageBot.py en tu editor o terminal. Antes de ejecutarlo, verifica dos cosas importantes del código. Primero revisa la línea donde está el token; debe estar correctamente pegado. Segundo revisa que no has cambiado la estructura del archivo, porque la ventana inicial depende de la clase ChannelIDDialog para pedir el ID del canal. No necesitas modificar nada más.

Para ejecutar el programa usa Python normalmente. Si estás en Windows, abre un CMD o PowerShell dentro de la carpeta donde está MessageBot.py y escribe python MessageBot.py. Cuando se abra la aplicación, lo primero que verás será una ventana solicitando el ID del canal. Pega el número que copiaste de Discord y confirma. En ese momento el código internamente guarda el ID en la variable global CHANNEL_ID y lanza un hilo que inicia el bot usando el token que pusiste al principio del archivo.

Cuando el bot se conecte correctamente, en tu terminal verás un mensaje como “Bot conectado como…”. También verás que el programa empieza a cargar los emojis de los servidores donde esté el bot. La interfaz gráfica se abrirá mostrando el constructor de embeds. Si todo está correcto, cuando presiones el botón “ENVIAR EMBED”, el mensaje se agregará a una cola y el hilo del bot lo enviará al canal cuyo ID ingresaste al inicio.

Si necesitas cambiar de canal, basta cerrar el programa, volver a ejecutarlo y escribir un nuevo ID en la ventana inicial. Si necesitas cambiar de bot, simplemente cambia el token en la línea de código correspondiente. No necesitas hacer ninguna otra configuración interna.
